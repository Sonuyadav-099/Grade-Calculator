
# Statement for Grade Calculator Project

## Problem Statement
Manually calculating averages, ranks, and grades for students can be time‑consuming and prone to mistakes.  
This project solves the problem by automating the process. It takes marks as input, validates them, calculates averages and highest scores, sorts students by total marks, and prints report cards with grades.

## Scope of the Project
The project is small but covers important basics of programming:
- Input and validation of marks
- Calculation of averages and highest marks
- Sorting students by total marks
- Printing report cards with grades
- Modular code structure with multiple files
- Simple testing to check grading logic

## Target Users
- Students who want to practice Python programming
- Teachers who want a quick way to prepare report cards
- Beginners learning how to build modular projects

## High-Level Features
- Clear input/output system
- Grading logic based on averages and highest marks
- Bubble sort for ranking students
- Report card generation with subject grades and overall grade
- Testing file to verify grading function
