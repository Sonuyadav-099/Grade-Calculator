# Grade Calculator Project

## Project Title
Grade Calculator Project

## Overview
This project is a simple Python program made to help calculate grades for students.  
It asks for marks in four subjects (Calculus, Programming Language, EVS, and English), checks if the marks are valid, calculates averages, finds the highest marks, sorts students by total marks, and finally prints report cards with grades.  
The project is modular, with separate files for input, grading, statistics, sorting, reporting, and testing.

## Features
- Enter student names and marks for four subjects
- Validate marks (no negative values or more than maximum)
- Calculate subject averages and overall average
- Find highest marks in each subject
- Sort students by total marks using Bubble Sort
- Print report cards with grades (S, A, B, C, D, F)
- Simple testing file to check grading logic

## Technologies / Tools Used
- Python (basic lists, loops, functions)
- Modular code structure (separate .py files for each part)
- Command line input/output
- Basic testing using print statements
